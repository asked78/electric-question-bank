# ⚡ 高压电工错题集

一个纯前端的高压电工作业考试刷题工具，内置精选题库，支持错题集、收藏、回收站等功能。

## 🚀 立即使用

**👉 [https://asked78.github.io/electric-question-bank/](https://asked78.github.io/electric-question-bank/)**

手机浏览器直接打开即可使用，所有数据保存在本地 localStorage。

## ✨ 主要功能

- 📚 全部题目 - 浏览题库所有题目
- ❌ 待重做错题 - 答错的题自动入集，集中复习
- ⭐ 收藏题目 - 重点题目一键星标
- 🆕 最近新增 - 按时间倒序展示新题
- 🗑 回收站 - 删除题目可恢复

## 💾 数据存储

所有做题记录（错题、收藏、完成进度）保存在**浏览器的 localStorage** 中，不会上传到服务器。
每个设备/浏览器独立保存，**更换设备或清缓存会导致数据丢失**。

## 🛠 本地运行

直接双击 `index.html` 即可在浏览器打开。
